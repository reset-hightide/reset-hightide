<p align="center"><b>🎴 <a href="https://github.com/reset-hightide/mtg-lands-calculator">Calculadora de Terrenos</a></b><br>
Quantos terrenos o seu deck precisa? Cole a lista. Leia a resposta. Compre uma mão de teste. Sem lista? Sorteie o deck médio de um comandante popular, direto do EDHREC. Baseada em regressão linear de 39 mil decks.<br>
<b>💡 Aprendi:</b> regressão linear num problema real, a API do Scryfall, o JSON aberto do EDHREC e a leitura de listas de texto do Archidekt, Arena, MTGO e Moxfield.<br>

<i><b>💡 Learned:</b> linear regression on a real problem, the Scryfall API, EDHREC's open JSON and parsing text lists from Archidekt, Arena, MTGO and Moxfield.</i></p>
